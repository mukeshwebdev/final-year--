13. COMMON ERRORS & FIXES
================================================================

Error                          | Fix
------------------------------|----------------------------------------------
"Cannot connect to database"  | PostgreSQL not running — start the service
"Token expired"               | JWT_SECRET missing in .env
"AI features not working"     | Python service not running — run python main.py
"Port already in use"         | Another app on 5000/3000 — kill it or change PORT in .env
"Seed fails: email exists"    | Run: npx prisma migrate reset  then re-seed
"Module not found"            | Run npm install in the failing service folder
"spaCy model not found"       | Run: python -m spacy download en_core_web_sm
"venv not activated"          | Run: venv\Scripts\activate  in ai-service folder
